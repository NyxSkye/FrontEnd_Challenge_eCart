User manual & help

Use this guide to navigate the Mlue challenge dashboard, run its working features, and understand what the sample results represent.

User manual

Get started with the interactive workspace.

1. Open the workspace

Choose Individual DSA Tasks in the navigation or select Launch. The task list is on the left; the selected task's controls and results appear in the main panel.

2. Select a challenge

Use the numbered task buttons to switch panels. The progress indicator shows the selected task number out of 10. Challenges without a working panel currently display an Under Construction message.

3. Run a challenge

  • Price Finder: enter a positive target price in rupees and select Search (or press Enter) to see the three closest products.
  • Top K Popular: choose how many products to show, then select Show Products.
  • Recommendations: type in the product field, choose an option from the suggestions, then select Get Recommendations.
  • Warehouse Optimizer: enter a positive capacity in kilograms, then select Optimize Cargo (or press Enter).

4. Read the algorithm notes

On implemented panels, expand “How It Works & Algorithm Details” to read the data-structure explanation and complexity comparison. Use Core CS Concepts for a guide to all ten roadmap topics.

Help & frequently asked questions

Notes about inputs, data, results, and features that are not yet available.

Why does a task show “Under Construction”?

The current workspace implements challenges 1, 2, 5, and 10. The other numbered tasks are roadmap entries and do not yet have interactive implementations.

Where do recommendations come from?

Recommendations are calculated from a small set of simulated browsing sessions included with the project. They demonstrate item-to-item co-view counting and are not live or personalized account data.

How are warehouse weights calculated?

The product catalog does not provide shipping weights. The optimizer assigns estimated integer weights using product category and, for some accessories, product names. The displayed values are illustrative.

Why are my results empty?

Check that the input is a valid positive number, and for recommendations make sure you selected a suggestion rather than only typing a product name. A product with no matching sample history can legitimately return no recommendations.

Can I undo or redo cart changes?

Undo/Redo Cart is listed in the project roadmap, but it is not currently implemented as an interactive dashboard feature.

Does this dashboard need an account or server?

The challenge pages are a static front-end demonstration built with HTML, CSS, and JavaScript. They use the local sample catalog and do not require a sign-in or server-side account.

Still need a pointer?

Read the algorithm explanations or return to the challenge workspace. No separate support contact is configured in this project.
