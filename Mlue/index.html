Smart Price Finder

Locates products closest to a target budget using Binary Search.

O(log N) Lookup
💡 How It Works & Algorithm Details ▼

Core Concept

Instead of scanning every product linearly, we pre-sort the catalog by price once. A binary search then pinpoints the exact or closest insertion index in logarithmic time, expanding two pointers outward to extract the K closest results.

Data Structure

Sorted Array: Contiguous memory enables $O(1)$ random access, making binary search possible.

Approach Time Complexity Space Complexity Notes
Initial (Linear Scan) O(N) O(1) Computes absolute differences across all $N$ products every search.
Optimized (Binary Search) O(log N + K) O(N) One-time O(N log N) sort, then sub-millisecond search per query.

🔥 Top K Popular Products

Calculates popularity based on rating × reviews using a Min-Heap of size K.

O(N log K)
💡 How It Works & Algorithm Details ▼

Core Concept

When $K \ll N$, a full array sort is wasteful. By maintaining a Min-Heap of size $K$, the smallest of our current top candidates stays at the root. We only swap if a new product beats the root, discarding lower-scoring items in logarithmic time.

Data Structure

Min-Heap (Binary Heap): $O(1)$ peek at minimum of top $K$, and $O(\log K)$ insert/delete.

Approach Time Complexity Space Complexity Notes
Full Sort O(N log N) O(N) Sorts entire catalog even if only top 3 items are needed.
Min-Heap (Size K) O(N log K) O(K) Optimal when $K$ is small. Memory never exceeds $K$ items.

🤝 Personalized Recommendations

Recommends products frequently co-viewed by other users using co-occurrence graphs.

O(U · P) Map
💡 How It Works & Algorithm Details ▼

Core Concept

Uses item-to-item collaborative filtering. For a selected product, we filter simulated browsing sessions to find users who viewed it, aggregate the co-occurrence counts of all other items they browsed, and rank the top results.

Data Structure

Hash Map (Frequency Table): Enables $O(1)$ updates to co-occurrence counts across user histories.

Approach Time Complexity Space Complexity Notes
Bipartite Traversal O(U · P) O(M) Traverses matching sessions and tabulates frequency of candidate items.
Top K Extraction O(M log K) O(M) Sorts or extracts the highest-frequency co-viewed products.
