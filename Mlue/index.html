The 10 Laboratory Challenges

A structured curriculum scaling from elementary lookups to graph algorithms and dynamic programming.

01 Binary Search

Smart Price Finder

Pinpoints the closest budget items within a sorted catalog in $O(\log N)$ time using dual-pointer expansion.

02 Min-Heap

Top K Popular Products

Ranks catalog items by reviews and ratings in $O(N \log K)$ without computing a full wasteful catalog sort.

03 LRU Cache

Recently Viewed

Maintains an ordered browsing cache using a Hash Map combined with a Doubly Linked List for $O(1)$ operations.

04 Dual Stacks

Undo / Redo Cart

Provides reversible cart modifications using dual execution history stacks to restore past cart states.

05 Hash Maps / Graph

Personalized Recommendations

Traverses co-occurrence browsing graphs to serve related items based on overlapping visitor histories.

06 Prefix Sums / Trees

Inventory Range Dashboard

Executes repeated aggregate inventory value lookups across flexible price bounds without full rescans.

07 Trie (Prefix Tree)

Product Autocomplete

Delivers real-time keystroke suggestions across titles, brands, and tags with fast prefix lookups.

08 Dijkstra's Algorithm

Smart Delivery Route

Finds the shortest weighted paths across hubs, warehouses, and customer delivery destinations.

09 Topological Sort

Bundle Dependency Checker

Detects circular dependencies and validates safe compilation ordering across prerequisite packages.

10 Dynamic Programming

Warehouse Knapsack

Selects value-maximizing freight packages within strict weight capacities using 0/1 knapsack memoization.
