Smart Price Finder

Locates products closest to a target budget using Binary Search.

O(log N) Lookup
💡 How It Works & Algorithm Details ▼

Core Concept

Instead of scanning every product linearly, we pre-sort the catalog by price once. A binary search then pinpoints the exact or closest insertion index in logarithmic time, expanding two pointers outward to extract the $K$ closest results.

Data Structure

Sorted Array: Contiguous memory enables $O(1)$ random access, making binary search possible.

Approach Time Complexity Space Complexity Notes
Initial (Linear Scan) O(N) O(1) Computes absolute differences across all $N$ products every search.
Optimized (Binary Search) O(log N + K) O(N) One-time O(N log N) sort, then sub-millisecond search per query.
